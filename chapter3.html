09 Tool Use（工具使用）

Agent 天生只有「動動嘴巴」（生成文字）。但是只要交給它 Tools（工具），它就能動手做事：

🧠 只有大腦（沒有武器）

  • 只能「紙上談兵」
  • 回答「怎麼游泳」但不會游泳
  • 無法播放音樂、無法畫圖
  • 無法操作任何軟體

⚔️ 大腦 + 武器（Tool Use）

  • 能「理論 + 實作」
  • 會算數學（計算機）
  • 上網找資料（瀏覽器）
  • 畫圖（ComfyUI）
  • 操作任何 App（MCP）
💡 生活中的例子：
想像一位「美食評論家」：
沒有工具：只能評論「這道菜看起來很好吃」
有工具：可以真的打開冰箱（工具）、拿食材（工具）、下廚煮飯（工具）、最後端出成品！

10 MCP（模型上下文協定）

MCP（Model Context Protocol）是 AI 世界的「USB 插槽」。不同軟體（Notion、瀏覽器、繪圖、學校系統）只要符合 MCP 標準，Agent 就能「即插即用」！

「插上哪個工具，Agent 就能用哪個 App！」
MCP 的三個角色：
  • Agent（主機）：發出指令的 AI 大腦
  • MCP Server（伺服器）：轉換語言的「翻譯官」
  • App（工具）：被操作的軟體（Notion、ComfyUI）
🎮 類比說明：
想像一個 Roblox 遊樂場：
遊戲廳的電源插座（MCP）是統一的標準規格，無論是遊戲機、點唱機、零食機，插上去就能用。
只要符合「插座標準」（MCP 協定），任何新設備（新 App）都能直接插入使用，不用重新佈線！

MCP 讓 Agent「什麼都能做」！
🔧 動手做時間（第六天）
  1. 在 OpenCode GUI 中，輸入「幫我開一個新 Notion 頁面，標題是『我的 AI 課程筆記』」—— 觀察 Agent 使用 Notion MCP 工具
  2. 對 Agent 說「把剛剛那頁的標題改成『我的學習筆記』」—— 觀察它使用「編輯/更新」工具
  3. 對 Agent 說「列出我 Notion 上所有的頁面」—— 觀察它用「搜尋/列出」工具
  4. 寫下：MCP 和一般的 API 訂閱有什麼不同？（提示：API 是客製化，MCP 是標準化）

用 ComfyUI 生成圖片的三大要素：
  • Prompt（提示詞）：描述你想要的圖，越詳細越好
  • Negative Prompt（負面提示詞）：告訴 AI「不要」畫什麼
  • Seed（種子）：固定的亂數種子，能重現同一張圖
🎮 類比說明：
你要找一位設計師畫一張貼圖：
模糊的描述：「畫一隻貓」→ 你可能得到任何東西
清楚的描述：「畫一隻橘色的、戴著藍色眼鏡、坐在星空下的貓，請用動畫風格」→ 得到你想要的圖！

Prompt 寫得越清楚，AI 畫得越符合期待。就像「命令越明確，士兵越不會搞錯任務」！
🔧 動手做時間（第七天）
  1. 在 OpenCode GUI 中開啟 ComfyUI 工作區
  2. 在輸入框輸入「一隻身穿太空裝的橘貓在月球上，動畫風格，色彩繽紛」並執行
  3. 換一個 prompt「同一隻貓但改成藍色眼鏡」，比較差異
  4. 加入 Negative Prompt「模糊、低畫質、多餘的手」再生成一次
  5. 使用同樣的 seed 再生成一次，觀察是否得到相同結果

⚔️ 第三章小挑戰：一鍵生成專屬貼圖
結合 Tool Use、MCP、ComfyUI，打造你的「自動貼圖工廠」！

🎯 挑戰目標

用 OpenCode GUI 打造一個「自動貼圖工廠」，能將文字描述轉換成超可愛的星球貼圖，並自動存到 Notion。串聯工具使用（Tool Use）、外部協定（MCP）、圖片生成（ComfyUI）三大能力。
提交流程截圖 + 生成圖片 + 300 字報告。

任務一：生成專屬星球貼圖

在 ComfyUI 利用文字生成 3 張不同主題的星球貼圖：
1. 「可愛的粉色星球，戴著小皇冠，微笑表情，柔軟的卡通風格」
2. 「湛藍色海洋星球，戴著太陽眼鏡，放鬆的度假心情，動畫風格」
3. 「彩虹色星球，戴著廚師帽，開心烘焙中，繽紛卡通風格」

任務二：串聯 MCP 建立貼圖目錄

在 Notion 建立一個「我的星球貼圖」資料庫頁面，包含這 3 張圖的：
1. 名稱
2. 主題描述
3. 生成的 Prompt（提示詞）
4. 圖片

任務三：一鍵產生新貼圖

用一句話讓 Agent 自動完成整個流程：
「我現在想要一張『森林綠色星球，戴著狐狸耳朵，害羞的表情』的貼圖，請幫我生成並存入貼圖目錄」
觀察 Agent 是否自動依序完成：ComfyUI 生成 → 存檔 → Notion 更新

任務四：撰寫 300 字報告

寫下：
1. Tool Use、MCP、ComfyUI 在本挑戰中各自扮演什麼角色？（3-4 句）
2. 如果沒有 MCP，你怎麼把圖片存到 Notion？（2-3 句）
3. Prompt 寫得好不好，對生成結果影響有多大？舉例說明（3 句）
4. 你未來還想讓 Agent 自動做什麼？（2-3 句）
