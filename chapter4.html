12 Multi-Agent（多 Agent 系統）

一個 Agent 能力有限。但是 多個 Agent 分工合作，就像是組了一支冒險小隊，每個人都有專長！
⚔️ 冒險小隊分工示意圖
👑 隊長
分配任務、決策
🛡️ 坦克
承受傷害、抵抗攻擊
💚 治療師
修復錯誤、補充資源
⚔️ 輸出
快速處理任務
每個角色各司其職，合力打敗 Boss！
多 Agent 系統的三種常見架構：

🏗️ 階層式

  • 一個「領導者」Agent 分配任務給「員工」Agent
  • 適合層級分明的組織
  • 例如：主管 → 員工

🤝 平行式

  • 多個 Agent同時處理不同任務
  • 適合需要大量產出的工作
  • 例如：多個翻譯員同時翻不同章節

🔄 接力式

  • 像接力賽，每個 Agent 處理完交給下一個
  • 適合有順序的流程
  • 例如：草稿 → 校稿 → 完稿
🎮 類比說明：
如果只有一位全能英雄，很累而且容易出錯。
但組一個小隊分工合作：
隊長負責指揮、坦克負責吸引仇恨、治療師負責補血、輸出負責打傷害 —— 整個團隊效率提升好幾倍！

多 Agent 系統 = 把大任務拆給不同專長的 AI 分工合作
🔧 動手做時間（第九天）
  1. 在 OpenCode 中，開啟多個 Agent，分別指派不同任務（例如：一個負責寫開頭、一個負責蒐集資料、一個負責總結）
  2. 對同一任務給「不同角色設定的 Agent」處理，比較差異（例如：一個扮演樂觀的、一個扮演謹慎的）
  3. 設計一個 3 人小隊分工表：寫下每個 Agent 的角色、任務、負責範圍
  4. 寫下：單一 Agent 和多 Agent 合作，各有哪些優缺點？

13 Delegation（授權任務）

Delegation 就是把任務授權給 Agent 處理。但就像借寶刀給隊友，要想清楚該給多大力道！
💪 完全授權（Full Autonomy）
Agent 自己決定所有事
適合：重複、無風險的任務
🧭 部分授權（Semi-Autonomy）
Agent 先提案，你審核
適合：需要人判斷的任務
🚦 需同意（Human-in-the-loop）
重要動作必須問你
適合：花錢、刪除、發文等
🎮 類比說明：
你有一把傳說的寶刀：
交給陌生人：他可能拿去亂砍（危險！）
完全不給：什麼都要自己來（好累）
聰明的做法：看清楚任務再決定給多少權限！

「授權」不是「放手不管」，而是「看清楚任務再決定給多少權限」

14 安全防護（Safety & Guardrails）

AI 很強大，但也可能做錯事。我們需要 Guardrails（安全護欄） 來保護自己：

⚠️ 需要防護的風險

❌ 未經允許就刪除檔案
❌ 亂花錢買東西
❌ 回覆不當內容
❌ 洩漏個人資料

🛡️ 三層防護網

✅ 規則設定（訂好不能違反的規則）
✅ 流程限制（重要步驟需人工確認）
✅ 事後審計（記錄所有動作可追蹤）
🔐 確認視窗（Human-in-the-loop）
Agent 想要執行：「刪除這個資料夾中的 3 個檔案」
這是一個不可逆的動作，需要你的確認。
✅ 允許
❌ 拒絕
安全三原則：
  • 最小權限：只給 Agent 完成任務所需的最低權限
  • 雙重確認：重要動作（刪除、花錢、發送）要有人工確認
  • 完整紀錄：Agent 做的每個動作都要留下紀錄，出問題可追究
🎮 類比說明：
冒險小隊進入地宮時：
亂衝：隊員走在前面踩到陷阱，全滅！
有偵查兵：先偵察路線，回報風險，再行動！

安全護欄就像偵查兵，先幫你探險、回報風險，確保整體安全。
🔧 動手做時間（第十天）
  1. 在 OpenCode 中設定「不要自動刪除任何檔案」的規則，然後叫 Agent 擬一份刪檔任務
  2. 練習布置一個「減少 email 通知」的任務，觀察它是否只做你要求的事
  3. 測試：給 Agent 一個「意外發送訊息」的指令，它是否有正確的確認護欄？
  4. 寫下：為什麼「最小權限」很重要？並列出 3 個需要人工確認的高風險動作

⚔️ 第四章小挑戰：組建你的「AI 冒險小隊」
運用多 Agent 協作 + 安全防護，打造一個團隊協作系統！

🎯 挑戰目標

用 OpenCode GUI 組建一個「AI 冒險小隊」，由至少 3 個不同角色的 Agent 分工合作完成一個專案，並加上安全護欄保護。
提交流程截圖 + 分工表 + 300 字報告。

任務一：組建你的冒險小隊

設計一支至少 3 人的 AI 小隊，分工如下：
1. 隊長 Agent：負責分配任務、統整結果
2. 資料收集 Agent：負責上網找資料
3. 審查 Agent：負責檢查內容正確性與安全性

主題任選，例如：「學校 10 周年校慶」或 「我家附近的美食地圖」

任務二：實際運作小隊

在你的主題上實際讓小隊運作，蒐集 3 個不同的資料（如：活動資訊、設施介紹、歷史沿革），
並讓 審查 Agent 最終檢查內容是否正確、有無遺漏、排版是否完整。

任務三：實作安全護欄

為你的小隊加上安全機制：
1. 設定「不得發布個人真實姓名、電話、住址」的規則
2. 設定「涉及金錢交易或刪除資料時必須人工確認」
3. 示範一次「資料收集 Agent 想進行一個高風險動作」，展示它如何被阻擋

任務四：撰寫 300 字報告

寫下：
1. 你設計的小隊有哪些角色？每個角色負責什麼？（3-4 句）
2. 多 Agent 合作時，遇到哪些協作上的困難？如何解決？（3 句）
3. 安全護欄如何保護你的小隊？如果沒有護欄會發生什麼事？（3 句）
4. 下次你還會怎麼改進你的小隊？（2 句）

📋 評分標準

評分項目 分數 說明
✅ 小隊設計 25 分 至少 3 個角色，分工明確、職責清楚
✅ 實際運作 25 分 成功蒐集 3 個資料，審查 Agent 有效把關
✅ 安全護欄 25 分 設定有效護欄，且能示範阻擋高風險動作
✅ 300 字報告 25 分 能清楚說明團隊架構與安全機制，具反思
